Workflow n8n

Un orquestador real, no una demo lineal.

El workflow v38 funciona como columna vertebral: recibe el brief, valida obligatorios, consulta herramientas externas, ejecuta decisiones, persiste el resultado y devuelve una salida estructurada para el portal.

Entrada controladaWebhook + validación de campos obligatorios antes de llamar a IA.
Agente con herramientasGPT-4.1 trabaja con patrón Tools Agent/ReAct para planificar con fuentes externas.
Ruta de refinamientoGPT-4o-mini permite ajustar un plan existente sin regenerar todo el viaje.

Ejemplo de lógica

La IA se usa dentro de reglas, no como caja negra.

El proyecto documenta entradas, salidas, puntos de decisión y estado de sesión. Esta forma de trabajar es clave para perfiles de AI Product y automatización: diseñar el sistema antes de “pedirle cosas” al modelo.

Aprendizajes

La IA aporta valor cuando el proceso está bien diseñado.

El mayor aprendizaje fue que la calidad no depende solo del modelo. Depende de contratos de datos, validación, fuentes externas, coste, trazabilidad, errores recuperables y una interfaz que haga comprensible el resultado.
