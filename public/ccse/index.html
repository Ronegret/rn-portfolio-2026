Problema

Estudiar para una prueba oficial no deberia generar dudas sobre si el material es correcto.

Durante mi propio proceso de nacionalidad detecté que muchas soluciones existentes eran confusas, visualmente saturadas o tenían errores en preguntas y respuestas. En una prueba importante, la experiencia debe transmitir precisión, calma y control.

01

Confianza

El usuario necesita saber que está practicando con información fiable y actualizada.

02

Claridad

Preguntas, respuestas y feedback tienen que leerse rápido, sin elementos que distraigan.

03

Accesibilidad

La herramienta debe funcionar en móvil, tablet y escritorio, con texto legible y controles claros.

Cuestionario CCSE en vivo

Proceso UX

De una necesidad personal a una herramienta de ayuda comunitaria.

Empatia

Detectar la inseguridad del usuario

El contexto de uso es sensible: el usuario estudia para un trámite importante. Por eso prioricé seguridad, precisión y facilidad de uso.

Definición

Reducir carga cognitiva

La interfaz separa pregunta, opciones y resultado para que estudiar no dependa de descifrar una pantalla compleja.

IA aplicada

Verificacion del contenido

Use Gemini para revisar y procesar el material, acelerando la validacion del banco de preguntas y respuestas.

Implementacion

Publicacion abierta

GitHub Pages permite acceso gratuito, rápido y sin instalación para cualquier persona que necesite practicar.

Decisiones UI

Una estética institucional, serena y fácil de estudiar.

La direccion visual usa borgona, dorado suave y fondos claros para comunicar seriedad sin volver la herramienta fria. Los componentes se disenan para lectura sostenida: contraste alto, jerarquia simple y acciones visibles.

  • Preguntas y respuestas con jerarquia clara.
  • Feedback rápido para aprender del error.
  • Controles grandes y fáciles de pulsar en móvil.
  • Estilo sobrio alineado con el contexto institucional.
